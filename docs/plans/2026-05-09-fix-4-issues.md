# Fix 4 Issues in The Sanguine Spear — Implementation Plan

> **For Hermes:** Use TDD cycle: RED → GREEN → REFACTOR. Each task = test first, then code, then verify.

**Goal:** Fix 4 rendering/UX issues in BattleScene using test-driven development.

**Architecture:** Extract pure testable logic from BattleScene where possible (timing state machines, pixel-snapping math, stat-counting animation). Fix Phaser rendering glue (scrollFactor, depth) directly.

**Tech Stack:** TypeScript, Vitest, Phaser 3

---

## Issue 1: Turn Banner Appears/Disappears Too Quickly

**Root cause:** `showTurnBanner` (line 2412) overlay lacks `setScrollFactor(0)`, so on scrolled maps the banner may be misplaced. Hold duration is 1200ms — borderline. Need longer linger.

**Fix:**
- Extract `TurnBannerTiming` pure class with phases: FADING_IN, HOLDING, FADING_OUT, DONE
- Increase hold from 1200ms → 2000ms
- Add `overlay.setScrollFactor(0)` and `overlay.setDepth(100)` to `showTurnBanner`

**Files:**
- Create: `src/game/ui/TurnBannerTiming.ts`
- Create: `src/game/ui/__tests__/TurnBannerTiming.test.ts`
- Modify: `src/scenes/BattleScene.ts` (showTurnBanner)

---

## Issue 2: Grid Lines Varying in Thickness During Camera Movement

**Root cause:** `drawGridLines()` draws lines at world coordinates `offsetX + x * TILE_SIZE`. When `camera.scrollX` has fractional values, lines render at sub-pixel screen positions, causing anti-aliased varying thickness.

**Fix:**
- Extract `snapLineToPixel(worldX, scrollX): number` pure function that returns pixel-snapped screen-space X, then converts back to world space
- Redraw grid lines on every camera move (in `updateVisibleTiles` path)
- Use rounded screen-space positions to ensure crisp 1px lines

**Files:**
- Create: `src/game/ui/GridLineSnapper.ts`
- Create: `src/game/ui/__tests__/GridLineSnapper.test.ts`
- Modify: `src/scenes/BattleScene.ts` (drawGridLines, updateVisibleTiles)

---

## Issue 3: Level-Up Stat Increment Animation

**Root cause:** The level-up screen shows old→new values with `▲` markers, but there's no animation of the numbers changing. The user wants to visually see stats count up.

**Fix:**
- Extract `StatCounter` pure class: given old/new value pairs, computes per-frame "current" value for counting animation
- Enhance `LevelUpDisplay` to support count-up phase per stat
- In BattleScene's animation loop, render counting numbers for increased stats
- Flash/highlight effect when a stat finishes counting up

**Files:**
- Create: `src/game/ui/StatCounter.ts`
- Create: `src/game/ui/__tests__/StatCounter.test.ts`
- Modify: `src/game/ui/LevelUpDisplay.ts`
- Modify: `src/game/ui/__tests__/LevelUpDisplay.test.ts`
- Modify: `src/scenes/BattleScene.ts` (showLevelUpSequence animation loop)

---

## Issue 4: Items Menu Not Centered When Camera Moved

**Root cause:** `showItemMenu` and `showItemConfirm` create `this.add.container(0, 0)` without `setScrollFactor(0)`. Children are positioned at `cam.width/2, cam.height/2` in world space, NOT screen space.

**Fix:**
- Add `overlay.setScrollFactor(0)` and `overlay.setDepth(100)` to:
  - `showItemMenu` (line 3033)
  - `showItemConfirm` (line 3137)
- Also fix `showTurnBanner` (line 2414) — part of Issue 1

**Files:**
- Modify: `src/scenes/BattleScene.ts` (showItemMenu, showItemConfirm)
